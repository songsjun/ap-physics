## 二、数据层：Dexie.js (IndexedDB)

### 存储配额（已验证）
- Chrome/Edge：可用磁盘的 60%（实际数十 GB）
- Firefox：约 2–5 GB
- Safari：约 1 GB，⚠️ **ITP 7 天无访问可能清除**（见第五节）
- 预估数据量：< 2 MB，所有浏览器绰绰有余

### Schema 定义

```typescript
// lib/db.ts
import Dexie, { type EntityTable } from 'dexie'

interface KnowledgePoint {
  id: string
  name_zh: string
  name_en: string
  unit: number
  ced_topic: string
  prerequisites: string[]
  openstax_sections: string[]
  week: number
  day: number
}

interface Resource {
  id: string
  title: string
  url: string | null
  content_body: object | null    // MC题、checklist等原生内容，IndexedDB直接存JS对象，无需序列化
  adapter_type: string           // external_manual | native_quiz | ai_graded_text | observation
  type: string
  platform: string
  tier: string                   // A | B | C
  estimated_minutes: number
  concepts: string[]             // multiEntry索引，支持数组元素查询
  week: number
  day: number
  slot_order: number
}

interface Completion {
  user_id: string
  resource_id: string
  status: string                 // not_started | in_progress | completed
  score: number | null
  score_max: number | null
  ai_feedback: string | null
  evidence_url: string | null
  completed_at: Date | null
}

interface DayUnlock {
  user_id: string
  week: number
  day: number
  unlocked_at: Date
}

export const db = new Dexie('PhysicsLearningDB') as Dexie & {
  knowledge_points: EntityTable<KnowledgePoint, 'id'>
  resources: EntityTable<Resource, 'id'>
  completions: EntityTable<Completion, never>
  day_unlocks: EntityTable<DayUnlock, never>
}

db.version(1).stores({
  knowledge_points: 'id, unit, week, day, [week+day]',
  resources:        'id, tier, week, day, slot_order, adapter_type, [week+day], [week+day+slot_order], *concepts',
  completions:      '[user_id+resource_id], user_id, resource_id',
  day_unlocks:      '[user_id+week+day], user_id, [user_id+week]',
})
```

### 核心查询实现（已验证可行）

```typescript
// lib/queries.ts

// 1. 当天A层资源，按顺序
export const getDayResources = (week: number, day: number, tier = 'A') =>
  db.resources
    .where('[week+day]').equals([week, day])
    .filter(r => r.tier === tier)
    .sortBy('slot_order')

// 2. 某用户某资源的完成记录
export const getCompletion = (userId: string, resourceId: string) =>
  db.completions.get({ user_id: userId, resource_id: resourceId })

// 3. 当天所有完成记录 + 通过率计算
export const getDayPassRate = async (userId: string, week: number, day: number) => {
  const resources = await getDayResources(week, day)
  const completions = await db.completions
    .where('user_id').equals(userId)
    .filter(c => resources.map(r => r.id).includes(c.resource_id))
    .toArray()
  const passed = completions.filter(c => (c.score ?? 0) / (c.score_max ?? 1) >= 0.75).length
  return resources.length > 0 ? passed / resources.length : 0
}

// 4. B层补救资源（concepts数组查询，关键：需要.distinct()）
export const getBRemediation = async (userId: string, conceptIds: string[]) => {
  const seen = await db.completions
    .where('user_id').equals(userId)
    .toArray()
    .then(cs => new Set(cs.map(c => c.resource_id)))

  return db.resources
    .where('concepts').anyOf(conceptIds)
    .filter(r => r.tier === 'B' && !seen.has(r.id))
    .distinct()    // multiEntry必须加，防止重复
    .toArray()
}

// 5. 检查日解锁状态
export const isDayUnlocked = async (userId: string, week: number, day: number) => {
  if (week === 1 && day === 1) return true  // 第一天始终解锁
  const unlock = await db.day_unlocks.get({ user_id: userId, week, day })
  return unlock !== undefined
}

// 6. 内容库初始化（首次加载时执行）
export const seedContentLibrary = async () => {
  const count = await db.resources.count()
  if (count > 0) return  // 已有数据，跳过
  const { concepts, resources } = await import('@/data/content_library.json')
  await db.knowledge_points.bulkPut(concepts)
  await db.resources.bulkPut(resources)
}

// 7. 内容库更新（content_library.json版本升级时）
export const updateContentLibrary = async () => {
  const { concepts, resources } = await import('@/data/content_library.json')
  await db.knowledge_points.bulkPut(concepts)  // bulkPut = upsert，安全幂等
  await db.resources.bulkPut(resources)
}
```

### Schema 迁移规则
- 新增字段：直接加入对象，旧记录该字段为 `undefined`，无需迁移
- 新增索引：`db.version(2).stores({ resources: '...新增字段...' })`
- 修改主键结构：需创建新表 + 数据迁移（尽量避免）

### 存储方案选型说明（OPFS 已评估排除）

评估过用 **OPFS（Origin Private File System）** 替代 IndexedDB，结论是不适合本项目：

- OPFS 是文件系统，无原生查询能力，不能直接过滤/排序结构化数据
- 间接方案（SQLite WASM over OPFS）需要 `COOP/COEP` 响应头，会破坏外部 iframe 嵌入，且 bundle 增加 ~1.5MB
- 我们的数据量 < 2MB、查询简单，Dexie.js 已完全满足

唯一适合引入 OPFS 的未来场景：需要在本地缓存大型文件（视频、PDF）时，与 IndexedDB 并用。

## 三、Repository 模式（数据访问抽象层）

所有组件通过 `IRepository` 接口访问数据，**不直接调用 Dexie.js**。迁移到 PostgreSQL 时只替换实现，组件代码不变。

### 接口定义


### IndexedDB 实现（MVP）

```typescript
// lib/repository/dexie.repo.ts
import { db } from '@/lib/db'
import type { IRepository } from './interface'

export class DexieRepository implements IRepository {
  async getDayResources(week, day, tier) {
    return db.resources
      .where('[week+day]').equals([week, day])
      .filter(r => r.tier === tier)
      .sortBy('slot_order')
  }

  async getCompletion(userId, resourceId) {
    return db.completions.get({ user_id: userId, resource_id: resourceId }) ?? null
  }

  async saveCompletion(completion) {
    await db.completions.put(completion)
  }

  async isDayUnlocked(userId, week, day) {
    if (week === 1 && day === 1) return true
    return (await db.day_unlocks.get({ user_id: userId, week, day })) !== undefined
  }

  async unlockDay(userId, week, day) {
    await db.day_unlocks.put({ user_id: userId, week, day, unlocked_at: new Date() })
  }

  async getBRemediation(userId, conceptIds) {
    const seen = new Set(
      (await db.completions.where('user_id').equals(userId).toArray()).map(c => c.resource_id)
    )
    return db.resources
      .where('concepts').anyOf(conceptIds)
      .filter(r => r.tier === 'B' && !seen.has(r.id))
      .distinct()
      .toArray()
  }

  async getDayPassRate(userId, week, day) {
    const resources = await this.getDayResources(week, day, 'A')
    const ids = resources.map(r => r.id)
    const completions = await db.completions
      .where('user_id').equals(userId)
      .filter(c => ids.includes(c.resource_id))
      .toArray()
    const passed = completions.filter(c => (c.score ?? 0) / (c.score_max ?? 1) >= 0.75).length
    return ids.length > 0 ? passed / ids.length : 0
  }

  async getFailedConcepts(userId, week, day) {
    const resources = await this.getDayResources(week, day, 'A')
    const failed: string[] = []
    for (const r of resources) {
      const c = await this.getCompletion(userId, r.id)
      if (c && (c.score ?? 0) / (c.score_max ?? 1) < 0.75) failed.push(...r.concepts)
    }
    return [...new Set(failed)]
  }

  async exportUserProgress(userId) {
    const completions = await db.completions.where('user_id').equals(userId).toArray()
    const unlocks = await db.day_unlocks.where('user_id').equals(userId).toArray()
    return { userId, exportedAt: new Date().toISOString(), completions, unlocks }
  }
}
```

## 四、AI 层：浏览器直调 Claude API

### 架构决策
- API Key 由用户在设置页手动输入，存 localStorage，**不上传任何服务器**
- 浏览器直接调 Claude API（`dangerouslyAllowBrowser: true`），无需 Edge Function
- AI 功能为可选：Key 未设置时优雅降级（隐藏 AI 评分入口）
- 流式响应（SSE）在浏览器端原生支持，体验与 Edge Function 代理一致

### API Key 管理

```typescript
// lib/ai.ts
import Anthropic from '@anthropic-ai/sdk'

const API_KEY_STORAGE = 'physics_anthropic_key'

export const apiKey = {
  get: (): string | null => localStorage.getItem(API_KEY_STORAGE),
  save: (key: string): void => { localStorage.setItem(API_KEY_STORAGE, key) },
  clear: (): void => { localStorage.removeItem(API_KEY_STORAGE) },
  isSet: (): boolean => !!localStorage.getItem(API_KEY_STORAGE),
}

function getClient(): Anthropic {
  const key = apiKey.get()
  if (!key) throw new Error('请先在设置页输入 Claude API Key')
  return new Anthropic({ apiKey: key, dangerouslyAllowBrowser: true })
}
```

### 自检题评分

```typescript
// lib/ai.ts（续）
export async function gradeCalculation(
  question: string,
  reference: string,
  studentAnswer: string,
  onChunk?: (text: string) => void
) {
  const client = getClient()
  const prompt = `你是AP物理1的辅导老师。学生解答了以下计算题，请按解题步骤评分并给出一句中文反馈。
题目：${question}
参考答案步骤：${reference}
学生答案：${studentAnswer}

输出格式（JSON）：
{"status": "passed|failed", "step_errors": ["错误描述"], "feedback": "一句话反馈"}`

  let result = ''
  const stream = await client.messages.stream({
    model: 'claude-sonnet-4-6',
    max_tokens: 500,
    messages: [{ role: 'user', content: prompt }],
  })
  for await (const event of stream) {
    if (event.type === 'content_block_delta' && event.delta.type === 'text_delta') {
      result += event.delta.text
      onChunk?.(event.delta.text)
    }
  }
  return JSON.parse(result) as { status: 'passed' | 'failed'; step_errors: string[]; feedback: string }
}
```

## 六、Safari ITP 风险与缓解

Safari 的 Intelligent Tracking Prevention 可能在 7 天无访问后清除 IndexedDB 数据。

```typescript
// app/layout.tsx 或 app/providers.tsx — 应用启动时执行
async function requestPersistentStorage() {
  if (navigator.storage?.persist) {
    const granted = await navigator.storage.persist()
    if (!granted) {
      // 向用户提示：Safari用户建议定期导出进度备份
      console.warn('Persistent storage not granted. Safari users may lose data after 7 days of inactivity.')
    }
  }
}
```

**用户侧缓解方案**：
1. 应用启动时调用 `navigator.storage.persist()`（需用户手势触发）
2. 在设置页提供「导出进度 JSON」功能（一键下载）
3. 提示 Safari 用户「将网页添加到主屏幕」（PWA 模式存储更稳定）

## 九、Flow Controller 实现

```typescript
// lib/flow.ts
import { repo } from './repository'
import type { Resource } from './db'

export type FlowAction =
  | { type: 'DAY_LOCKED' }
  | { type: 'PRESENT'; resource: Resource }
  | { type: 'SHOW_REMEDIATION'; resources: Resource[] }
  | { type: 'RETRY_A_LAYER' }
  | { type: 'DAY_COMPLETE'; passRate: number }

export async function getNextAction(
  userId: string,
  week: number,
  day: number
): Promise<FlowAction> {

  if (!(await repo.isDayUnlocked(userId, week, day))) {
    return { type: 'DAY_LOCKED' }
  }

  // 遍历A层资源，找第一个未完成的
  const aResources = await repo.getDayResources(week, day, 'A')
  for (const resource of aResources) {
    const completion = await repo.getCompletion(userId, resource.id)
    if (!completion || completion.status !== 'completed') {
      return { type: 'PRESENT', resource }
    }
  }

  // 所有A层完成，检查通过率
  const passRate = await repo.getDayPassRate(userId, week, day)
  if (passRate >= 0.75) {
    const nextWeek = day === 7 ? week + 1 : week
    const nextDay = day === 7 ? 1 : day + 1
    await repo.unlockDay(userId, nextWeek, nextDay)
    return { type: 'DAY_COMPLETE', passRate }
  }

  // 未达标，查B层补救
  const failedConcepts = await repo.getFailedConcepts(userId, week, day)
  const remediation = await repo.getBRemediation(userId, failedConcepts)
  if (remediation.length > 0) {
    return { type: 'SHOW_REMEDIATION', resources: remediation }
  }

  return { type: 'RETRY_A_LAYER' }
}
```
